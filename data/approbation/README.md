# Результаты апробации (режим «Тест»)

Сюда кладутся CSV-файлы, которые участники выгружают кнопкой «Экспорт результатов (CSV)»
на странице «Упражнения → Режим «Тест»». Каждый файл — ответы одного или нескольких
участников: строка на ответ, разделитель `;`, UTF-8.

| Столбец | Значение |
|---|---|
| `participant` | имя или код участника (одинаковый в предтесте и посттесте) |
| `stage` | `pre` — предтест (набор A), `post` — посттест (набор B) |
| `attempt_id`, `set_id` | попытка и версия набора заданий |
| `started_at`, `finished_at` | начало и конец попытки (пусто — тест не закончен) |
| `task_no`, `item_id` | номер задания и его идентификатор в корпусе |
| `phenomenon`, `level`, `subtype` | явление, уровень текста, подтип (the/a/an, 个/специальное, падеж) |
| `correct_answer`, `answer`, `correct` | верный ответ, ответ участника, 1/0 |
| `time_ms` | время на задание, мс |

Анализ: `python -m pipeline approbation` → `reports/approbation.md`.

Результаты хранятся в браузере участника до экспорта; незаконченные попытки и повторные
прохождения того же этапа в расчёт не входят (учитывается первая завершённая попытка).
