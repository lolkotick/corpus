# Сохранённые ответы LLM

Сюда pipeline записывает ответы модели (по одному JSON-файлу на проверенную пару).
Файлы хранятся в git: при сборке без `ANTHROPIC_API_KEY` сохранённые ответы
всё равно применяются, а повторная сборка с ключом не тратит запросы на уже
проверенные пары. Имя файла — хэш запроса (модель, промпт, текст пары): если
пара изменилась, она будет проверена заново.
