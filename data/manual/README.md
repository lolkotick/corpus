# Ручные правки

`overrides.json` создаётся командой

```
python -m pipeline import-csv путь/к/исправленному/corpus.csv
```

и хранит только отличия от автоматического результата: исправленный текст,
статус (`checked` / `corrected`), комментарий, удаление пары. При каждой
сборке правки применяются заново, поэтому пересборка их не затирает.
Файл можно редактировать и вручную (UTF-8, JSON).
