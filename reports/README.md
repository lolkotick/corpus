# Отчёты для практической главы курсовой

Все файлы в этой папке **генерируются** скриптами pipeline — не правьте их вручную,
а пересоберите. Отчёт, для которого ещё нет данных (эталона или результатов теста),
содержит сообщение и инструкцию вместо чисел.

## Как пересобрать одной командой

```powershell
python scripts/build_reports.py            # Windows, Linux, macOS
python scripts/build_reports.py --no-llm   # без платных запросов к LLM при сравнении методов
make reports                               # то же самое (Linux/macOS)
```

Эквивалент — `python -m pipeline reports`. Перед этим корпус должен быть собран
(`python -m pipeline build`). Время сборки отчётов — несколько секунд; нейросетевое
выравнивание (LaBSE) добавляет загрузку модели.

## Какие отчёты есть

| Отчёт | Что внутри | Данные | Команда отдельно |
|---|---|---|---|
| `corpus.md` | описание корпуса: тексты, объём, разметка по текстам, падежи, 量词, артикли, выравнивание | `web/public/data/` | `python -m pipeline corpus-report` |
| `evaluation.md` | точность, полнота, F1 (95% ДИ) для выравнивания, артиклей, 量词, падежей; матрица ошибок по падежам | `data/gold/gold.json` | `python -m pipeline evaluate` |
| `aligners.md` | сравнение методов выравнивания: метрики по эталону, время, согласие методов, 10 расхождений | тексты + `gold.json` | `python -m pipeline compare-aligners` |
| `errors.md` | типы ошибок разметки, частоты и по 3 примера | `gold.json` | `python -m pipeline errors` |
| `approbation.md` | предтест и посттест: средний балл, прирост, критерии, ошибки по явлениям | `data/approbation/*.csv` | `python -m pipeline approbation` |

Рядом с каждым отчётом лежат его таблицы (`*.csv`) и графики (`*.png`), в папке `docx/` —
копия отчёта в формате Word.

`evaluation_*.csv`, `aligners_metrics.csv` и т. п.

## Как вставлять в Word

- **Готовый документ.** `docx/<отчёт>.docx`: A4, поля 30/15/20/20 мм, Times New Roman 14 пт,
  полуторный интервал; таблицы — настоящие таблицы Word с подписью «Таблица N — …» над ними;
  графики — в конце, с подписью «Рисунок N — …» под ними. Нумерацию таблиц и рисунков
  при переносе в курсовую поправьте под общую.
- **Таблицы.** Откройте `*.csv` в Excel (UTF-8 с BOM, разделитель `;`, десятичная запятая —
  открывается без настройки) и скопируйте диапазон в Word. Или скопируйте таблицу из
  `docx/`.
- **Графики.** `*.png` — 300 dpi, 16 см по ширине (ширина полосы набора; квадратные — 10 см):
  «Вставка → Рисунок», масштаб 100 %.

## Единый стиль графиков

Все графики рисует `pipeline/charts.py`:
- шрифт DejaVu Sans (кириллица), подписи и числа по-русски, десятичная запятая;
- 300 dpi, точный размер без обрезки;
- цвета языков такие же, как на сайте: EN — синий `#1f5fad`, ZH — терракотовый
  `#b5421f`, RU — зелёный `#007a52`; выравнивание — янтарный `#c28100`;
- ряды P / R / F1 и этапы теста — первые цвета палитры, проверенной на различимость при
  дальтонизме; значения подписаны прямо на столбцах.

Иероглифов на графиках нет (в среде сборки не было шрифта с CJK): счётные слова
подписаны пиньинем, а иероглифы есть в таблицах и Markdown.

## Честность данных

- `gold.json` составляет только эксперт вручную в режиме «Проверка»; скрипты его не
  создают и не дополняют.
- Тестовые данные в `pipeline/tests/fixtures/` помечены как синтетические. Если такой
  файл подать на вход, отчёт выводит предупреждение «синтетические данные».
- Время работы методов зависит от компьютера: указывайте в курсовой, на чём проводился замер.
