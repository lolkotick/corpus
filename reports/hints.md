# Согласие эксперта с подсказками ИИ

**Данных для сравнения нет:** файл data/gold/hints.json не найден.

Отчёт нужен, только если эталон размечался с подсказками ИИ:

1. `python -m pipeline hints-template` — заготовка `data/gold/hints.json`.
2. Модель вписывает в заготовку вердикты и обоснования.
3. Эксперт проверяет контрольные пары вслепую, остальные — с подсказками (сайт → «Проверка» → «Загрузить подсказки ИИ»), и экспортирует `gold.json`.
4. `python -m pipeline hints-agreement`.

Подсказки не являются эталоном; скрипт их не создаёт и не дополняет.
